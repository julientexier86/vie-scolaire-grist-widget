# Vie scolaire AED — widget Grist (miroir de publication)

Widget Grist du planning de la vie scolaire (collège Jean Jaurès, Gençay). Ce dépôt GitHub sert les fichiers via GitHub Pages ; le dépôt de référence (README détaillé, licence AGPL-3.0, tests, notices) est sur la Forge des communs numériques : https://forge.apps.education.fr/texierjulien/vie-scolaire-grist

## Versions (dossiers figés, ne jamais modifier un dossier publié)

- `v1/` : v1.0.0, première version validée sur données fictives.
- `v2/` : **v2.0.0, version recommandée.** Identifie l'AED connecté via la table `Comptes`, grise les listes des collègues dans l'espace AED, retire les boutons mot de passe et déconnexion.
